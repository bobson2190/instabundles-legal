# Privacy Policy

**Last Updated:** September 2026

This Privacy Policy explains what information is collected, how it is used, and how it is managed when you use this Discord bot ("the Bot"). We prioritize user privacy, adhere to data minimization principles, and aim for full transparency regarding outbound links.

---

### 1. Data We Collect
The Bot collects and stores **only** the minimum structural data required to deliver game bundle notifications:

* **Server IDs (Guild IDs):** To identify which Discord servers are active subscribers.
* **Channel IDs:** To know which specific channels within a server should receive deal alerts.

### 2. Data We DO NOT Collect
To protect user privacy, the Bot **does not** collect, store, or process:
* Personal user data (usernames, profile pictures, email addresses, IP addresses).
* Individual Discord User IDs.
* Message content or chat history.
* Purchasing history or payment details.

### 3. How We Use the Data
Stored Server IDs and Channel IDs are used exclusively to deliver game bundle notification alerts to your designated channels. This structural data is never sold, rented, or shared with third parties.

### 4. Affiliate Links & Third-Party Websites
Notifications delivered by the Bot contain outbound affiliate links to external game bundle storefronts (e.g. Humble Bundle, Fanatical, etc.) 

* **No Tracking:** Clicking an affiliate link redirects you to an external merchant. The Bot does not track individual user clicks, log IP addresses, or build purchasing profiles.
* **External Policies:** Third-party websites operate under their own privacy policies and cookie practices. We recommend reviewing their policies when visiting external stores.

### 5. Data Storage & Security
Stored IDs are kept in a secure database accessible only by the Bot developer. Because we do not collect personal identifiers, the stored data cannot be used to track or identify individual human users.

### 6. Data Retention & Deletion
We keep Server and Channel IDs only as long as the Bot is active in your server to maintain notification settings.

* **Automatic Cleanup:** You can stop all data usage at any time by removing (kicking/banning) the Bot from your server.
* **Manual Deletion Requests:** Server administrators may request immediate manual deletion of all stored server data from our database by contacting the developer via Discord.

### 7. Compliance
This policy is designed to comply with Discord Developer Terms and major privacy frameworks (including GDPR and CCPA) regarding minimal data retention and user disclosure.

---

### Contact
If you have questions about this Privacy Policy or wish to request data deletion, please contact the developer via Discord.
